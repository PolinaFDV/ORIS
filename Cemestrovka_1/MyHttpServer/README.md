# Wiki по настольной игре «Взрывные котята»

Представляет собой веб-сервер, написанный на C# с использованием `HttpListener`.

## Технологии
- **Backend:** C# (.NET 10), HttpListener.
- **База данных:** PostgreSQL.
- **ORM:** Собственная реализация (`MiniHttpServer.ORM`).
- **Шаблонизатор:** Собственная реализация (`MiniHttpServer.HtmlTemplating`).
- **Frontend:** HTML, CSS, чистый JS (без фреймворков). WYSIWYG-редактор — Quill (CDN).

## Функционал
- Каталог карт (динамическая загрузка из БД).
- Страница карты с подробным описанием (WYSIWYG-форматирование).
- Форма обратной связи (AJAX, валидация с регулярными выражениями, ограничение символов).
- Административная панель (авторизация, CRUD для карточек, загрузка изображений).
- Поиск по картам (JS).

## Запуск проекта вручную
1. Установите PostgreSQL и создайте базу `exploding_kittens`.
2. Выполните SQL-скрипт из файла `database.sql` в pgAdmin.
3. Откройте файл `settings.json` и укажите актуальную строку подключения.
4. Запустите проект в Visual Studio / Rider или через `dotnet run` в папке `MyHttpServer`.
5. Перейдите по адресу: `http://127.0.0.1:8888/home/index`.

## Запуск проекта через Docker
1. В корне проекта (где лежит `docker-compose.yml`) выполните команду:
   ```bash
   docker-compose up --build
2. Приложение будет доступно по адресу: http://127.0.0.1:8888/home/index.
3. База данных автоматически инициализируется скриптом database.sql.
